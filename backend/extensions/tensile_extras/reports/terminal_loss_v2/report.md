# 말단 모델 범위 v2 — 실제 데이터 회귀 검토

**상태: Draft.** 이 보고서는 저장된 198건 결과를 요약합니다. 자동 말단 범위는 공칭 변환 뒤 정렬 전에 적용되며, 원취득 순서의 prefix를 유지합니다. 자동 정책은 지원된 말단 급락과 설정된 공칭 변형률 상한 0.50 중 더 이른 끝을 선택합니다. 수동 정책은 끝 변형률을 받으며 0.50 초과 입력도 허용합니다. 이 단계는 네킹 판정이나 별도 곡선 crop을 대신하지 않습니다.

## 대표 5건

![대표 5건의 원곡선 전체와 v1/v2 유지 범위](terminal-v2-five-case.png)

유지 행 수는 끝 행 인덱스에 1을 더한 값입니다. 차이는 `v2 − v1`이며, 음수는 v2가 더 짧은 prefix를 선택했음을 뜻합니다.

| 시편 | 원행 | 기존 v1 유지 | 신규 v2 유지 | v2 선택 이유 | 차이 |
| --- | ---: | ---: | ---: | --- | ---: |
| PC1 · Oxford 50 mm/min 시험 1 | 1,068 | 1,067 | 486 | 50% 상한 | −581 |
| PC5 · Oxford 5 mm/min 시험 2 | 2,017 | 2,016 | 961 | 50% 상한 | −1,055 |
| BT3 · Sandia 304L | 2,587 | 2,587 | 2,467 | 50% 상한 | −120 |
| M04DPMMA | 131 | 130 | 130 | 급락; 기존 v1과 동일 | 0 |
| MTIL-M01A1018CR_1 | 211 | 210 | 210 | 급락; 기존 v1과 동일 | 0 |

전체 198건은 플라스틱 50건과 금속 148건입니다. v2와 현재 v1 출력의 끝점은 151건에서 같고, 47건은 50% 상한 정책으로 달라졌습니다. v2 종료 사유는 급락 114건, 상한 47건, 전체 유지 37건입니다. 198건 모두에서 출력은 원행 prefix였고, 모든 열과 단위를 보존했습니다.

PC5의 급락 뒤 부분 회복과 BT3의 원행 909–1640 회복 구간은 선택된 v2 prefix 안에 남습니다. 자료만으로 이 사건의 원인을 찢어짐이나 파단으로 확정하지 않았습니다. 50%는 사용자가 제안한 모델링 상한이지 보편적인 물리 유효성 경계가 아닙니다. 이 회귀 검토만으로 새 급락 경계가 실제 물리 모델에서 더 우월하다는 점이 입증된 것도 아닙니다.

## 보조 확인과 한계

- 수동 끝 변형률 0.30과 0.80: 각 3건, 총 6건 모두 기대한 prefix와 일치.
- JSON recipe 재실행: 대표 3건 모두 동일.
- v1 대조는 현재 v1 함수 출력과의 비교입니다. R13/R15 frozen oracle 대조는 하지 않았습니다.
- E, 항복, 재료 모델, 카드의 검증 완료를 주장하지 않습니다.
- 제출 데이터: [간결 CSV](terminal-v2-concise.csv), [간결 요약 JSON](terminal-v2-compact-summary.json). 전체 검증 JSON은 작업기록으로만 보관하고 이 보고서에는 첨부하지 않았습니다.

## 검증 상태

Focused 36건 통과, Ruff·mypy·build 통과. 전체 스위트는 3,021 통과, 40 skip, 2 fail로 보고되었습니다. 실패는 플랫폼 확장 계약 문서 미갱신과 선택 time 열을 필수로 취급하는 기존 walkable 검사입니다. 해당 플랫폼 소유 경로의 인계가 필요하며, 이 PR은 Draft 상태입니다.

## 화면 확인

PC1 한 사례에서 자동 v2는 index 485까지 486행을 유지했고, 수동 끝 변형률 0.80은 index 773까지 774행을 유지했습니다. 두 경우 모두 화면의 E 1.527 GPa, 0.2% 오프셋 항복 60.53 MPa, 네킹 후보 0.07138은 같았습니다. 이는 한 사례의 UI 확인이며 전체 E 검증을 뜻하지 않습니다. 말단 범위 단계는 공칭 변환 뒤·정렬 앞이고 네킹 및 crop은 별도 단계입니다. crop이 켜진 이 화면에서 최종 300행은 말단 유지 행 수와 다릅니다.

입력 time 열의 선언 단위는 `1`이어서 초로 해석하지 않았고, 화면 노트대로 엄격 변형률 축으로 fallback했습니다. 원자료와 단위는 수정하지 않았으며 새 결과나 recipe는 저장하지 않았습니다.
